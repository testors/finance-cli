# Finance Server UI 시안

모바일·데스크탑 공통 웹앱의 디자인과 탐색 흐름을 검토하는 정적 시안입니다.
계좌, 거래, 인증 상태, 작업 기록은 모두 합성 데이터입니다. 은행이나 Finance API에 요청하지 않으며 입력 내용을 저장하지 않습니다.

제품 구현은 [웹앱 구현 계획](../../docs/web-app-plan.md)의 단계와 완료 기준을 따릅니다.

여러 은행과 개인·개인사업자·법인은 [업무 프로필과 기관 연결 설계](../../docs/profiles-and-connections.md)에 따라 확장합니다. 현재 시안에는 공통 업무 프로필 전환, 여러 은행의 통합 계좌, 기관 연결별 로그인·서명 수단 설정이 아직 반영되지 않았습니다. 홈택스 내부의 개인/사업장 선택은 구현 시 공통 프로필 전환으로 통합합니다.

## 로컬 미리보기

이 디렉터리에서 실행합니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

<http://127.0.0.1:8765/>에서 열고 상단의 데스크탑·모바일 버튼으로 구성을 비교할 수 있습니다. 좁은 화면에서는 모바일 구성이 자동 적용됩니다.

## 포함된 흐름

- 좌상단에서 뱅킹·지로·세금을 전환하고 영역별 메뉴 사용. 각 영역의 마지막 화면 유지.
- 모바일은 같은 영역 전환과 자주 쓰는 메뉴 3개·전체 메뉴 사용.
- 뱅킹: 계좌·잔액·거래·이체 내역, 예시 CSV 저장, 이체 확인, 보안매체·한도 조회.
- 홈택스: 개인·사업장 선택, 세액·납부·환급·고지, 신고·서식·접수증, 예시 HTML 저장.
- 전자세금계산서: 매출·매입, 상세, 새 초안, 여섯 사유의 수정 초안, 확인과 예시 발급 결과.
- 지로: 예시 고지 자료·기한 해석, 연결 준비와 지원 상태.
- 공통: 기관을 통합한 작업 기록, 인증서·접속 관리, CLI 전체 기능의 분류와 지원 상태.

미구현인 실시간 지로 조회·납부, 새 세금 신고·납부 등은 메뉴에 `준비 중`으로 표시하고 실제 `disabled` 속성으로 비활성화합니다. 서버에서만 관리할 인증서 발급·이전 및 로컬 진단 도구는 미구현 기능과 별도로 표시합니다.

실제 인증, 이체, 세션 연장, 접속 철회는 구현하지 않았습니다. 실제 계좌번호나 인증 정보는 입력할 필요가 없습니다.

`dist/`의 HTML·CSS·JavaScript를 직접 편집합니다. 기존 뱅킹 화면은 `app.js`, 영역별 화면과 기능 목록은 `modes.js`, 예시 동작은 `interactions.js`에 있습니다. 빌드나 외부 라이브러리가 필요하지 않습니다. `.openai/hosting.json`은 정적 출력 위치만 지정하며 외부 배포는 하지 않았습니다.
